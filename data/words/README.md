# Word lists (open-license pipeline)

Generated by `scripts/words/build_word_lists.py`. Do not hand-edit these files; change the
script or the blocklist and regenerate instead.

## Source

- Dictionary: [tdd-ai/hunspell-tr](https://github.com/tdd-ai/hunspell-tr), pinned commit
  `7302eca5f3652fe7ae3d3ec06c44697c97342b4e` (tag `v1.1.1`), license MPL-2.0.
- Frequency signal: [`wordfreq`](https://github.com/rspeer/wordfreq) (CC BY-SA 4.0), used only
  as an internal filter/ranking signal. No frequency values are stored in these files.
- The TDK dictionary (sozluk.gov.tr) and the Zemberek dictionary are explicitly not used.

## How to regenerate

```sh
pip install -r scripts/words/requirements.txt
python3 scripts/words/build_word_lists.py
```

The script downloads the pinned Hunspell dictionary snapshot (cached under
`scripts/words/.cache/`, not committed) and deterministically rewrites every file in this
directory.

## Files

- `valid-4.txt`, `valid-5.txt`, `valid-6.txt`, `valid-7.txt`: one normalized word per line
  (Turkish uppercase: `i`→`İ`, `ı`→`I`), sorted. This is the full guess-validation list for
  that length.
- `candidates-4.csv` ... `candidates-7.csv`: columns `word,length,needs_review,reason`.
  Subset of the valid list with `wordfreq` zipf frequency ≥ 3.0, infinitive verb forms
  (`-mak`/`-mek`) excluded, likely-English loanwords excluded
  (`candidates.is_likely_english`), and family-safety blocklist matches excluded. No
  frequency value is stored. `needs_review=1` rows have few Hunspell inflection flags, which
  correlates with proper nouns, abbreviations and loanwords; they should be spot-checked
  before use as a daily answer.
- `summary.json`: counts per length plus the pinned source commit, for quick verification.

## Known limitations

- The inflection heuristic (see `scripts/words/inflection.py`) only strips nominal suffixes
  (possessive, case, plural). Hunspell's `tr_TR.dic` also contains fully inflected verb forms
  (e.g. negative/past conjugations); those are not filtered and can surface in the candidate
  lists. A verb-conjugation and consonant-softening heuristic was tried and reverted (see
  `scripts/words/README.md` "Quality notes"): it wrongly dropped independent dictionary words
  that happen to share a verb's or a softened root's surface form (e.g. "geçmiş", "altmış",
  "içecek", "gelecek", "düğünü", "kendini"). Manual review of `needs_review=0` candidates
  before promoting them to daily answers is still recommended.
- `needs_review` is a heuristic (low inflection-flag count), not a verified proper-noun/foreign-
  word detector.

## Headword vs. inflected form (Plan 012 U1)

`inflection.py`'s heuristic tries to tell a genuine headword (keep) from a derived nominal
form (drop) by comparing `wordfreq` zipf frequency: a word is dropped only when the root it
could be sliced into (longest matching suffix first) is at least as frequent as the word
itself, as a real inflected form usually is (e.g. EVLER vs. EV). Before this fix the
heuristic dropped a word whenever *any* known root existed regardless of frequency, which
wrongly rejected real headwords ending in a suffix-like sequence (e.g. KOYUN as KOY + -un,
BOYUN as BOY + -un) — the short slice produced by a coincidental suffix match ("ko", "bo")
is usually not a meaningful root at all. New valid words from this fix that are not yet in
`data/words/seed/valid_words.sql` are listed in
`data/words/seed/valid_words_012_additions.sql` for the owner to apply by hand
(Invariant 4).
